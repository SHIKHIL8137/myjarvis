## 1. Architecture & Runtime Overview

Mark LVII is a PyQt6 desktop voice-first AI assistant built around two inference paths:
1. **Primary Cloud Path (`main.py`, `core/gemini.py`)**: Google Gemini Live API (`google-genai`, bidirectional WebSocket audio + multimodal vision frames + function calling + sliding-window context compression + `session_resumption` handles), paired with REST/OpenAI-compatible fallback models via `providers`.
2. **Offline Local Engine Pipeline (`providers/engine_pipeline.py`, `providers/stt_whisper.py`, `providers/tts_piper.py`)**: Local `faster-whisper` STT + local LLM provider + `piper-tts` / ElevenLabs synthesis.
3. **Host Control & Background Services**:
   - File operations (`actions/file_controller.py`), accessibility/OCR/vision (`core/screenview.py`, `actions/screen_processor.py`), app process matching (`core/appidentity.py`).
   - Checkpointed persistent background task queue (`core/tasks/engine.py`, `store.py`, `brain.py`, `agents.py`, `tools.py`, `web.py`).
   - 5-stage Deep Research runner (`core/tasks/research.py`).
   - Unified scheduled/startup/idle Routines Engine (`core/routines/engine.py`, `rules.py`, `actions/routines.py`).
   - Remote Phone Dashboard & Cloud Second Body (`dashboard/server.py`, `core/cloud.py`).
   - Plugin & Dynamic Action discovery (`core/plugin_loader.py`, `core/action_loader.py`).

Unlike Jarvis's FastAPI + React/TypeScript/WebGL + SQLAlchemy/PostgreSQL + LangGraph + Ollama-first local-airgap architecture, Mark LVII is tightly coupled to a PyQt6 desktop HUD process (`main.py`, 3,078 lines) and file-backed JSON persistence (`core/tasks/store.py`, `core/routines/engine.py`).
